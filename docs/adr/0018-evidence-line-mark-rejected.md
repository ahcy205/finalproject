# 0018. 근거에서 질문과 가까운 줄을 표시하는 방법은 쓰지 않는다

- 상태: 기각
- 날짜: 2026-10-27

## 배경

"방 불은 몇 시에 꺼야 돼?"는 검색이 정확하다(1위 규칙 제3조). 그런데 제3조 한 조문에 "출입시간 06:00-23:00"과 "천정등 00:00-06:00 소등"이 함께 있어서, 모델이 2회 중 1회 "23:00 소등"이라고 섞어 답했다. 이 답은 Jev 검증(ADR 0015)이 숨겼다.

"인원 점검 몇 시에 해?"도 오류로 기록돼 있었지만, 확인해 보니 지어낸 답이 아니었다. 답이 두 곳(안내 제26조 매일 24:00, 규칙 제12조 매주 수요일 저녁 정기점검)에 있었고, 평가는 24:00만 정답으로 봤다. 그래서 평가 정답을 고쳤다(PR #63).

## 시도한 방법

모델에게 근거를 넘길 때 여러 줄짜리 근거마다 질문과 가장 가까운 줄(bge-m3 유사도)에 `▶`를 붙이고, 근거 머리에 "(▶는 질문과 가장 가까운 줄)"을 적었다. 검색 자료와 지시문은 그대로 두었다. 관리자 답변 초안과 챗봇에 함께 적용했다.

표시한 줄 자체는 맞았다. 소등 질문에서는 제3조의 소등 줄이 표시됐다.

## 측정

챗봇 평가 2회(exaone3.5:7.8b, Jev 검증). 기존 결과는 `2026-10-27-chat-bus-table-1/2.json`, 시도 결과는 `2026-10-27-chat-line-mark-1/2.json`이다.

| | 기존 | 줄 표시 |
|---|---|---|
| 사실 정확도 | 0.89 / 0.91 | 0.80 / 0.91 |
| 잘못 거절 | 0.08 / 0.08 | 0.13 / 0.08 |
| 숨긴 답 | 2 / 3 | 4 / 3 |

질문별 결과 (2회 중 맞게 보인 횟수)

- 소등: 1 → 0. 표시가 맞았는데도 2회 모두 "23:00 이후 소등"이라고 답했고, **Jev 검증을 2회 모두 통과해 학생에게 보였다.**
- 흡연 2 → 0, 금요일 석식 2 → 0(배식 시간 "오후 7시 30분"을 지어냄), 전기장판 1 → 0
- 인원 점검 0 → 1, 벌점 감면 1 → 2, 기숙사비 환불 1 → 2

## 결정

쓰지 않는다. 코드는 머지하지 않았다.

- exaone3.5:7.8b는 근거 형식이 조금만 바뀌어도 다른 질문의 답이 흔들린다. 지시문을 늘렸을 때 나빠졌던 것(ADR 0010)과 같은 경향이다.
- 표시가 정확해도 모델이 그 줄을 따르지 않았다. 근거를 넘기는 방식을 바꾸는 것으로는 이 오류를 줄이기 어렵다.

## 알게 된 것

- Jev 검증은 "23:00 소등"처럼 근거에 있는 숫자를 다른 주제에 붙인 답을 놓칠 수 있다. 다음에는 모델을 쓰지 않는 검사(답 문장의 주제어와 시각이 근거의 같은 줄에 있는지 확인)를 검토한다.
