## 새 ADR 쓰는 법

`NNNN-짧은-영어-이름.md`로 만들고 아래 목차를 씁니다.

```markdown
# NNNN. 제목

- 상태: 제안 | 채택 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD

## 배경
무엇이 문제였고 어떤 제약이 있었나

## 결정
무엇을 하기로 했나

## 검토한 다른 안
각 안과 고르지 않은 이유

## 결과
좋아지는 점, 감수하는 점, 나중에 다시 볼 조건
```
