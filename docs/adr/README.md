# 결정 기록 (ADR)

되돌리기 어려운 결정을 **무엇을, 왜, 무엇을 포기하고** 골랐는지 기록합니다. 결정 하나에 파일 하나이고, 이미 쓴 내용은 고치지 않습니다. 결정을 바꿀 때는 새 ADR을 추가하고, 예전 ADR의 상태를 "대체됨(→ 새 번호)"으로 바꿉니다.

| 번호 | 제목 | 상태 |
|---|---|---|
| [0001](0001-record-decisions.md) | 결정을 ADR로 기록한다 | 채택 |
| [0002](0002-local-only.md) | 로컬 실행 전용, 배포하지 않는다 | 채택 |
| [0003](0003-api-backward-compatibility.md) | 앱 API는 하위 호환을 지킨다 | 채택 |
| [0004](0004-template-partials.md) | 화면 공통 부분은 include 조각으로 나눈다 | 채택 |
| [0005](0005-postgresql-pgvector.md) | PostgreSQL + pgvector로 전환한다 | 제안 |

## 새 ADR 쓰는 법

`NNNN-짧은-영어-이름.md`로 만들고 아래 목차를 씁니다.

```markdown
# NNNN. 제목

- 상태: 제안 | 채택 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD

## 배경
무엇이 문제였고 어떤 제약이 있었나

## 결정
무엇을 하기로 했나

## 검토한 다른 안
각 안과 고르지 않은 이유

## 결과
좋아지는 점, 감수하는 점, 나중에 다시 볼 조건
```
