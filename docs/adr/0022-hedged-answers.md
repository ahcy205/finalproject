# 0022. "명시되어 있지 않지만, ~입니다"로 답한 챗봇 답은 숨기지 않고 검증으로 넘긴다

- 상태: 채택
- 날짜: 2026-11-01

## 배경

챗봇 평가에서 답할 수 있는 질문의 8–12%가 학생에게 보이지 않았다("잘못 거절"). 최근 평가 4회(`2026-10-28-chat-verify-1/2`, `2026-11-01-chat-numbers-1/2`)에서 숨긴 답 23개를 나눠 보았다.

- **판단 모델(Jev)·시각 점검이 숨긴 15개**: 대부분 실제로 틀린 답이었다. 예: 흡연 벌점을 "18점"(벌점표의 항목 번호)이라고 함, "23:00 소등", 셔틀 방향을 반대로 답함. 제대로 숨긴 것이다.
- **"답을 찾지 못했어요"로 숨긴 8개**: 모두 `opens_with_not_found` 규칙에 걸렸다. 이 규칙은 답의 앞 두 문장에 "명시되어 있지 않"이 있으면 숨긴다. 그중 6개는 이런 답이었다.
  - "전기장판은 명시적으로 언급되어 있지 않지만, 제10조에서 전열기 사용을 금지합니다 [3]"
  - 학생 말(전기장판)과 규칙 말(전열기)이 다르거나, 근거에 정확한 시각이 없을 때 모델이 이렇게 말을 돌린다.
  - 규칙은 원래 범위 밖 질문에 "명시되어 있지 않습니다 [5]"처럼 관계없는 번호를 붙인 답을 거르려고 만든 것이다(ADR 0011). 그런데 "없습니다"와 "없지만 ~입니다"를 구분하지 못했다.

## 결정

1. `opens_with_not_found`에서 "없다"는 말 바로 뒤에 **지만 / 으나 / 은데 / 는데**가 이어지면(예: "명시되어 있지 않지만", "확인되지 않았지만") "자료에 없다"로 세지 않는다.
   - 이런 답은 다른 답과 똑같이 시각 점검과 판단 모델 검증을 거친다.
   - "명시되어 있지 않습니다"처럼 끝맺는 문장은 지금처럼 숨긴다.
2. 보여 주는 답의 **끝 문단에 붙은 거절 문구**("근거 자료에서 확인할 수 없습니다. 생활관에 직접 문의해 주세요.")는 지운다. 모델이 답을 다 한 뒤 지시문의 거절 문구를 덧붙이는 경우가 있어, 앞의 답과 어긋나 보였다.

## 측정

**구현 전, 저장된 결과로 확인**: 챗봇 평가 결과 14개 파일에 새 규칙을 적용했다.

- 숨김에서 풀리는 답은 서로 다른 답 23개였다. 모두 답할 수 있는 질문의 답이었다(인원 점검 9, 벌점 감면 6, 전기장판 5, 지각 벌점 2, 무단 외박 벌점 1).
- 범위 밖 질문의 답은 하나도 풀리지 않았다. 그런 답은 "명시되어 있지 않습니다"로 끝맺기 때문이다.
- 풀린 23개를 시각 점검과 Jev 검증에 실제로 다시 넣었다.

| | 개수 |
|---|---|
| 학생에게 보이게 됨 | 20 |
| 그중 틀린 답 | 0 |
| 다시 숨겨짐 | 3 |

- 다시 숨겨진 3개 중 2개는 틀린 답이었다(지각 벌점을 "지시사항 불이행 5점", 무단 외박을 "외부인 숙박 퇴관"이라고 함).
- 보이게 된 답 1개는 끝에 거절 문구가 붙어 있었다. 결정 2로 지운다.

## 감수하는 점

- 말을 돌린 답이 틀렸는지는 판단 모델에 맡긴다. 범위 밖 질문에 "명시되어 있지 않지만, 일반적으로…"처럼 지어낸 답이 나오면 판단 모델이 걸러야 한다. 평가의 범위 밖 거절률로 계속 확인한다.

## 추가 결정: 학생 말과 규칙 말을 모델에게 알려 준다 (#89)

말을 돌리는 원인 자체도 줄인다.

- 질문에 `synonyms.yaml`의 학생 말이 있고, 그에 맞는 규칙 말이 근거에 실제로 있으면, 근거 아래에 한 줄을 넣는다. 예: "질문의 '전기장판'은 근거의 '전열기'에 해당합니다." 관리자 답변 초안도 같은 프롬프트를 쓴다.
- `synonyms.yaml`에 "외박 신청 안", "몰래 외박" → "무단 외박"을 더했다. 모델이 "외박 신청 없이 자고 오면"을 벌점표의 "외부인 동반/숙박(퇴관)"과 헷갈렸다. 정답은 "무단 외박 7점"이다.

- 남은 숨김은 주로 틀린 답이다: "23:00 소등", 석식 시각을 근거에 없는 "7시 30분~9시"로 답함, 신입생 질문에 "자정까지 출입"을 덧붙임.

  - 의자 파손은 벌점 점수(10점)를 말하지 않았다. 틀린 숫자를 말하지는 않았다.
