# 0002. 로컬 실행 전용, 배포하지 않는다

- 상태: 채택
- 날짜: 2026-10-26

## 배경

이 프로젝트는 팀 프로젝트로 AWS EC2에 배포됐었지만, 지금은 포트폴리오로 관리한다. 코드 점검에서 배포용 설정 문제가 나왔다: `DEBUG=True`, `ALLOWED_HOSTS=['*']`, CORS 전체 허용, 코드에 들어 있던 `SECRET_KEY`.

## 결정

배포하지 않는다. 저장소는 로컬 실행 기준으로 유지한다.

- `DEBUG`, `ALLOWED_HOSTS`, CORS 설정은 **일부러 그대로 둔다.**
- `SECRET_KEY`는 배포와 상관없이 공개 저장소에 노출되면 안 되므로 환경변수 `DJANGO_SECRET_KEY`로 분리했다(PR #21). `DEBUG=False`에서는 환경변수가 없으면 서버가 시작되지 않는다.

## 검토한 다른 안

- **배포용 설정까지 갖추기:** 배포 대상(서버, 도메인, HTTPS)이 정해지지 않은 상태에서 설정만 바꾸면, 검증할 수 없는 설정이 생긴다.

## 결과

- 좋아지는 점: 개발과 검증이 단순하다.
- 감수하는 점: 지금 설정 그대로는 인터넷에 공개하면 안 된다.
- 다시 볼 조건: 배포하기로 하면 이 ADR을 대체하는 새 ADR을 쓰고 `DEBUG`, 허용 호스트, CORS, 정적 파일 서빙, HTTPS를 먼저 정한다.
