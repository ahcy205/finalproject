# 0010. 답변 초안 지시문은 규칙을 늘리지 않고 예시로 보여 준다

- 상태: 채택
- 날짜: 2026-10-27

## 배경

ADR 0008의 모델 비교에서 exaone3.5:7.8b의 약점은 아래와 같았다. 검색 문제(전기장판)는 ADR 0009로 고쳤고, 이번에는 지시문만 바꾼다.

- 범위 밖 질문에 상식으로 추측을 덧붙임 ("수강신청은 학기 시작 약 한 달 전부터")
- 벌점표의 항목 번호 `[13]`을 근거 번호처럼 씀
- 셔틀 시간표의 방향(학교로 오는 편 / 나가는 편)을 혼동
- 비슷한 항목을 섞음 (인원 점검 매일 24:00 ↔ 수요일 호실 점검·대청소)

## 시도와 측정

모델은 exaone3.5:7.8b, 검색은 동의어 보강(ADR 0009) 후 상태로 고정했다. 질문 42개, `evaluate_answer_drafts`. 모델 출력이 실행마다 달라서 채택 후보는 두 번씩 쟀다. 원문은 `knowledge/eval/results/2026-10-27-*.json`에 있다.

|---|---|---|---|---|---|---|
| 개선 전 (1회차 / 2회차) | 0.93 / 0.97 | 0.94 / 0.91 | 0.05 / 0.03 | 0 / 0 | 0.60 / 0.40 | 3.8초 |

범위 밖 질문 중 모델까지 간 6개를 사람이 읽고, 근거에 없는 구체적인 내용(숫자, 시기, 다른 자료와의 연결)을 지어낸 답을 셌다.

| 지시문 | 1회차 | 2회차 |
|---|---|---|
| 개선 전 | 3 (도서관 시간 추측, "학기 시작 약 한 달 전", 관계없는 공지 인용) | 2 (도서관 시간 추측, 관계없는 공지 인용) |

- **A안은 오히려 나빠졌다.** 규칙이 길어지자 `[1]` 대신 "제10조에 따르면"처럼 글로 인용하는 일이 늘었고(정답 근거 인용 0.88), 범위 밖 질문에는 숫자까지 지어냈다.
- **B안**
  - 인용이 두 번 모두 완벽했다(정답 근거 인용 1.00, 형식 문제 0).
  - 셔틀 방향 혼동이 사라졌다.
  - 범위 밖 질문에서 지어낸 구체적 내용이 없었다. 다만 "학교 학사일정을 확인하세요"처럼 일반적인 안내는 남아 있다.
- **B안의 사실 정확도가 조금 낮은 이유**
  - 두 번 모두 "관계 부서에 통보"를 "생활관 관리 부서에 알려야"라고 썼다. 의미는 맞지만 채점 문구(`관계 부서`)와 달라 틀린 것으로 셌다. 새 지시문에 유리하도록 채점 기준을 바꾸지는 않았다.
  - 실제로 틀린 답은 2회차의 "소등 23:00"(규칙은 00:00) 1건이다.
  - 개선 전에도 "인원 점검 시간"을 두 번 모두 틀렸다(수요일 22:00).
- **잘못 거절 0.03:** 인원 점검 질문 1건이다. 매일 24:00 점검을 맞게 쓰고도 "정확한 시간은 확인할 수 없다"는 문장을 덧붙여서, 거절 문구로 세어졌다.

## 결정

B안을 쓴다 (`knowledge/answering.py`).

- 규칙은 5개로 짧게 둔다. "상식으로 추측해 덧붙이지 않는다", "근거 본문 안의 항목 번호는 근거 번호가 아니다"를 기존 규칙에 한 구절씩 더했다.
- 예시 2개를 둔다: 근거로 답하는 예(다리미실), 거절하는 예(축제). 평가 질문과 겹치지 않는 내용으로 골랐다.
- 근거 목록 바로 뒤에 "근거만 사용, [번호] 인용, 답할 수 없으면 거절 문구만"을 한 줄로 다시 쓴다(`REMINDER`). 7–8B 모델은 앞쪽의 긴 지시보다 바로 앞의 말을 더 잘 따른다.

## 한계

- 실행마다 결과가 1–2문제씩 달라진다. 두 번 잰 평균으로 판단했지만 표본은 작다.
- 비슷한 항목을 섞는 문제(소등 시간, 인원 점검)는 줄었지만 남아 있다. 관리자 확인이 필요한 이유다.
- 지시문을 바꾸면 `python manage.py evaluate_answer_drafts`로 두 번 이상 재고 이 표와 비교한다.
