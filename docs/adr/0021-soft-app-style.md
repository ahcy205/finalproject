# 0021. 화면을 둥근 카드와 아이콘 중심의 "부드러운 앱" 모양으로 바꾼다

- 상태: 채택 (ADR 0020의 색·글꼴·화면 구조는 그대로 두고 모양을 바꾼다)
- 날짜: 2026-10-31

## 배경

ADR 0020의 "생활관 안내판" 디자인을 모든 화면에 적용한 뒤, 사용자는 화면이 딱딱하고 대충 만든 느낌이라고 평가했다. 이 디자인은 선으로 구분한 목록과 표, 굵은 검은 구분선, 번호판 모양이 중심이었다.

사용자가 참고로 보여 준 화면은 세 가지다.

- 학생 기숙사 앱: 이름을 불러 주는 인사, 큰 카드, 아이콘 타일
- 임대 관리 대시보드: 흰 카드, 색이 들어간 아이콘
- AI 챗봇: 옅은 그라데이션 배경, 환영 문구, 둥근 추천 질문, 떠 있는 입력창

학생이 휴대폰 앱처럼 쓰는 서비스라 이 방향이 맞다고 판단했다. 홈과 챗봇 시안을 휴대폰·PC 캡처로 보여 주고 승인을 받은 뒤 전체 화면에 적용했다.

## 결정

1. **모양만 바꾸는 층을 따로 둔다**(`static/css/dorm-soft.css`). `dorm.css` 다음에 불러온다. 색 이름(`--dg-*`)과 글꼴(Pretendard)은 ADR 0020 그대로 쓴다.
   - 카드: 흰색, 모서리 20px, 옅은 그림자
   - 입력칸·버튼: 모서리 12px
   - 탭: 알약 모양
   - 굵은 검은 구분선은 쓰지 않는다
2. **아이콘을 쓴다.** 외부 라이브러리 없이 `templates/web/_icon.html`에 필요한 선 아이콘만 그려 둔다(24px 격자, 선 굵기 1.8).
   - 묶음마다 옅은 바탕색을 정한다: 생활 = 민트·하늘, 안내 = 연보라, 커뮤니티 = 살구, 관리 = 진녹색
   - 아이콘은 훑어보기에 도움이 되는 곳에만 쓴다: 바로가기 타일, 목록 줄, 화면 제목, 빈 상태
3. **홈**
   - 녹색 인사말: 날짜, "안녕하세요, ○○님", 내 방
   - 오늘 상태 카드: 출입·소등, 다음 셔틀은 황동색
   - 아이콘 바로가기 8개
   - 카드: 내 외박 신청, 오늘 식단, 최근 공지
4. **휴대폰 아래 탭 막대**(960px 미만): 홈, 신청(직원은 관리), 챗봇, 게시판, 마이. 지금 묶음에 `aria-current`를 단다. 위쪽 메뉴 서랍은 그대로 둔다.
   - '신청' 탭은 신청 화면(외박·입실 신청, 신청 완료, 내 신청 현황)에서만 켠다. 식단·셔틀·편의시설은 상단 메뉴에서는 '생활' 묶음이지만 신청이 아니다. (#79)
   - 화면 키보드가 열리면 탭 막대를 숨기고 챗봇 입력창을 키보드 바로 위에 둔다. (#81)
   - 키보드 초점 표시는 테두리만 그리고 부품의 모서리 값은 바꾸지 않는다. (#80)
5. **상단 막대는 흰색에 녹색 글자로 바꾼다.** 반투명 흐림 효과(`backdrop-filter`)는 쓰지 않는다. 막대 안에 있는 서랍(`position: fixed`)의 위치 기준이 화면에서 막대로 바뀌어, 휴대폰에서 페이지가 730px로 넓어지고 서랍이 제대로 펼쳐지지 않았다.
6. **챗봇**
   - 환영 화면: 아바타, 인사, 2열 추천 질문 카드, 옅은 그라데이션 배경
   - 떠 있는 둥근 입력창
   - 답변 옆 작은 아바타, 출처는 둥근 칩
7. **나머지 화면**
   - 공통: 제목 옆 아이콘과 한 줄 설명, 카드로 묶은 양식과 목록, 아이콘과 문장이 있는 빈 상태
   - 게시판·공지: 표를 유지한다. 테스트가 글 번호 칸을 확인하고, 휴대폰에서는 이미 줄마다 쌓여 보인다.

## 확인

- 모든 화면(45가지 상태)을 휴대폰 390px와 PC 1280px로 캡처해 검토했다. 휴대폰에서 페이지가 옆으로 넘치지 않는지 `scrollWidth`로 확인했다.
- 테스트를 추가했다.
  - 아래 탭 막대가 학생·직원 화면에서 지금 묶음을 표시하는지
  - 템플릿에서 쓰는 아이콘 이름이 모두 실제 그림을 그리는지(이름이 틀리면 빈 아이콘이 되는 실수를 막음)

## 감수하는 점

- 카드와 그림자가 늘어 화면이 이전보다 길어진다.
- 편의시설 분류 버튼은 좁은 휴대폰에서 줄을 바꾸지 않고, 그 안에서 옆으로 밀어 본다.
- `dorm.css`에는 예전 모양의 규칙이 일부 남아 있다. `dorm-soft.css`가 그 위를 덮는다. 쓰지 않게 된 규칙(예전 안내판, 굵은 구분선, 목록 몇 가지)은 지웠다.
