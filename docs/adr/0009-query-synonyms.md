# 0009. 학생이 쓰는 말을 규정 용어로 바꿔 검색어를 보강한다

- 상태: 채택
- 날짜: 2026-10-26

## 배경

"전기장판 써도 돼?"는 임베딩 모델 세 개와 LLM 세 개가 모두 틀린 질문이다(ADR 0006, 0008). 규칙에는 "전열기, 기타 난방/취사 도구"라고만 적혀 있어서, 의미 검색도 키워드 검색도 제10조를 찾지 못했다. 근거에 답이 없으니 LLM은 "규정에 없다"거나 "개인 사용 가능"이라고 썼다. 학생은 "히터", "커피포트", "통금", "룸메"처럼 규정에 없는 일상어로 묻는다.

## 결정

- `knowledge/data/synonyms.yaml`에 "학생이 쓰는 말 → 규정에 적힌 말" 목록을 둔다. 예: `전기장판: [전열기, 난방 도구]`, `통금: [출입시간]`.
- 검색할 때 질문에 왼쪽 말이 있으면 오른쪽 말을 질문 끝에 덧붙인다(`knowledge.search.expand_query`). 의미 검색과 키워드 검색 모두 덧붙인 질문을 쓴다.
- 목록 작성 규칙
  - 평가 질문에 맞추지 않고, 일상어를 규정 용어로 옮기는 것만 넣는다.
  - 너무 흔한 말("기숙사")이나 다른 단어 속에 들어가는 짧은 말("술" → "기술", "수술")은 넣지 않는다.

## 측정 (bge-m3)

평가 질문 32개:

| | hit@1 | hit@5 | MRR |
|---|---|---|---|
| 보강 전 | 0.72 | 0.97 | 0.826 |
| **보강 후** | **0.75** | **1.00** | **0.854** |

평가 질문 32개 중 7개에 목록의 단어가 들어 있다. 그래서 평가 질문에 과적합됐는지 보려고, 평가에 없는 새 질문 10개로 정답 순위를 따로 비교했다(`-`는 5위 밖).

| 질문 | 정답 | 보강 전 | 보강 후 |
|---|---|---|---|
| 방에서 히터 틀어도 돼? | 제10조 | 5 | 3 |
| 커피포트 가져가도 되나요? | 제10조 | 4 | 3 |
| 온수매트 써도 돼요? | 제10조 | - | 3 |
| 밥솥으로 밥 해먹어도 돼? | 제10조 | - | 3 |
| 강아지 데려와서 키워도 돼? | 제10조 | 2 | 1 |
| 맥주 한 캔 정도는 마셔도 돼? | 벌점표 | 1 | 1 |
| 전자담배는 괜찮아? | 벌점표 | - | 4 |
| 입사 신청은 어떻게 해? | 안내 제9조 | 2 | 2 |
| 퇴사하면 기숙사비 환불돼? | 안내 제21조 | 1 | 1 |
| 룸메가 너무 시끄러워서 방 옮기고 싶어 | 안내 제15조 | 1 | 1 |

5위 밖이던 3개를 찾게 됐고, 나빠진 질문은 없다.

## 검토한 다른 안

- **LLM으로 질문 다시 쓰기:** 목록 없이도 동의어를 만들 수 있지만, 검색할 때마다 모델을 한 번 더 불러야 해서 수 초가 더 걸린다. 학생 챗봇에서는 응답 시간이 중요하다.
- **규칙 원문에 동의어 추가:** 화면에 보이는 규정 문구가 바뀌므로 하지 않는다.
- **임베딩 모델 미세조정:** 데이터가 적고, 모델을 바꿀 때마다 다시 해야 한다.

## 결과

- 목록에 없는 일상어는 여전히 놓칠 수 있다. 실제 문의에서 놓친 질문이 나오면 목록에 추가하고 다시 측정한다.
- 덧붙인 말 때문에 유사도가 조금 올라갈 수 있다. 범위 밖 질문 10개에는 목록의 단어가 없어 근거 부족 기준(0.45, ADR 0007)에는 영향이 없다.
