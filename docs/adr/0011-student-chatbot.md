# 0011. 학생 챗봇은 공개 자료만 쓰고, 검사를 통과한 답만 보여 준다

- 상태: 채택
- 날짜: 2026-10-27

## 배경

RAG 4단계로 학생이 직접 묻는 챗봇을 만든다. 관리자 답변 초안(ADR 0007–0010)과 같은 검색·모델을 쓰지만 큰 차이가 하나 있다. **사람의 확인 없이 학생에게 답이 바로 간다.** 그래서 틀린 답이 나가는 것을 막는 장치가 더 필요하다.

설계 검토에서 정한 것:
- 챗봇 종류: 사내·학교 FAQ형 (자주 묻는 질문에 바로 답하고, 못 답한 질문을 찾아 자료를 보강)
- 근거: 공개 자료만 (규칙·안내·셔틀·식단·공지). 다른 학생의 문의·답변은 개인정보를 가려도 쓰지 않는다.
- 인용 검사에 실패한 답: 숨기고 관련 자료 링크만 보여 준다.
- 한 번에 질문 하나 (앞 대화를 기억하지 않음)
- 범위: 웹 화면 `/chatbot/`, 앱 API, 익명 대화 기록(180일)과 👍/👎

## 결정

`knowledge/chat.py`의 `answer_question()`이 질문 하나에 답한다. 학생에게 보여 줄 상태는 네 가지다.

| 상태 | 조건 | 학생에게 보이는 것 |
|---|---|---|
| answered | 아래 검사를 모두 통과 | 답 + 인용한 근거의 제목·링크 |
| no_answer | 근거 유사도 < 0.45, 모델이 거절 문구만 씀, 또는 **앞 두 문장에서 "자료에 없다"고 함** | "답을 찾지 못했어요. 문의를 남겨 주세요" |
| unverified | 인용 번호가 없거나 없는 번호를 인용 | "근거를 확인하지 못해 보여 드리지 않았어요" + 관련 자료 3개 링크 |
| error | Ollama가 꺼짐 등 | "지금은 챗봇을 쓸 수 없어요" |

- **지시문은 관리자 초안용(ADR 0010)을 그대로 쓴다.** 학생용으로 따로 쓴 지시문은 측정에서 나빠졌다(아래).
- **"앞 두 문장" 검사:** 범위 밖 질문에 모델이 "졸업 학점은 자료에 명시되어 있지 않습니다 [5]"처럼 관계없는 번호를 붙이면 인용 검사를 통과해 버린다. 인사말을 뺀 앞 두 문장에 "명시되어 있지 않", "포함되어 있지 않", "확인할 수 없" 같은 말이 있으면 답을 찾지 못한 것으로 본다. 제대로 된 답은 앞 문장에서 바로 사실을 말하고, 단서("다른 별칭은 확인할 수 없습니다")는 뒤에 붙는다는 관찰에 기댄다.
- 질문은 500자까지만 쓰고, 검색·모델에 넘기기 전에 개인정보를 가린다.

## 측정

`python manage.py evaluate_answer_drafts --mode chat`. 학생이 실제로 보는 것만 채점한다: 숨긴 답은 답하지 않은 것으로 세고, "거절"은 답을 보여 줬는지로 센다. exaone3.5:7.8b, 질문 42개, 두 번씩. 원문은 `knowledge/eval/results/2026-10-27-chat-*.json`에 있다.

| 방식 | 사실 정확도 | 정답 근거 인용 | 잘못 거절 | 범위 밖 거절 | 시간 중앙값 |
|---|---|---|---|---|---|
| 학생용 지시문 (2~4문장, 인사말 없이) | 0.90 / 0.79 | 0.94 / 1.00 | 0.25 / 0.16* | 0.50 / 0.70* | 2.3초 |
| 관리자 초안 지시문 | 0.93 / 1.00 | 0.97 / 0.94 | — | 0.60 / 0.70* | 3.2초 |
| **관리자 초안 지시문 + 앞 두 문장 검사 (채택)** | **0.97 / 0.90** | **0.97 / 0.94** | **0.03 / 0.06** | **0.80 / 0.90** | 3.0초 |

\* 이 두 줄은 거절을 "답 속에 거절 문구가 있는지"로 센 값이다. 맞는 답 끝에 "확인할 수 없는 부분은 문의해 주세요"를 붙인 경우도 거절로 세어져, 채택안과 같은 기준이 아니다.

- **학생용 지시문을 버린 이유:** "통금은 06:00까지", "소등 23시"처럼 사실 오류가 늘었고, 맞는 답 뒤에 거절 문구를 붙여 학생이 보기에 헷갈리는 답이 많았다.
- **설계 때 정한 통과 기준**
  - 정답 근거 인용 ≥ 0.95: 평균 0.955로 통과
  - 잘못 거절 ≤ 0.1: 통과
  - 범위 밖 질문에서 지어낸 내용 0건: **1건 미달** (아래)

## 한계 (사용자 승인 후 진행)

- **지어낸 내용 1건:** "휴학 신청은 어떻게 해?"에 1회차에서 "퇴관할 때 휴학 증명서를 함께 내는 것이 좋다"는, 근거에 없는 서류 안내를 덧붙였다. 휴학은 규정상 퇴관 사유라 반쯤 관련 있는 질문이어서 검사를 통과했다.
- **앞 두 문장 검사의 부작용:** "늦게 들어오면 벌점 몇 점?"에 7점이라고 맞게 답했지만, 첫 문장이 "명시되어 있지 않지만…"으로 시작해 숨겨졌다(회당 1건 정도).
- **대응:** 화면에 출처 링크와 "AI 답변은 틀릴 수 있어요" 안내를 둔다. 익명 기록과 👎로 이런 사례를 모아 평가 질문에 추가하고 다시 측정한다(FAQ형 개선 순환). 지시문을 더 다듬는 일은 실제 기록이 쌓인 뒤에 한다.
- 7–8B 모델로는 지어내기를 0건으로 보장하기 어렵다. 실제 운영한다면 더 큰 모델이나 답변 문장별 근거 검증을 검토한다.
